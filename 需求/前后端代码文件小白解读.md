# 前后端代码文件小白解读

> 面向零基础：用大白话说明「每个文件是干什么的」「里面大概有什么代码」。  
> 路径相对仓库根目录。技术细节以源码为准；本文只做导读，不替代逐行阅读。

---

## 怎么读这份文档

可以把整个项目想成一家餐厅：

| 角色 | 对应 | 干什么 |
|------|------|--------|
| 服务员 / 点菜屏 | **前端** `frontend/` | 你看到的页面、按钮、表格、聊天框 |
| 厨房 | **后端** `backend/` | 登录校验、存文件、切文档、检索、调大模型 |
| 仓库 / 冰箱 | Postgres、Redis、Qdrant | 存账号数据、缓存、向量索引（不在本文逐文件展开） |

**一条完整业务链（小白版）：**

登录 → 建知识库 → 上传/AI 写文档 → 解析切块并做成向量 → 提问时先检索相关段落 → 大模型根据段落写回答 → 管理员看统计/管用户。

## 一、前端 `frontend/`

技术栈可以记成：**Vue 3（页面）+ TypeScript（类型）+ Vite（本地跑起来）+ Element Plus（按钮表格）+ Pinia（登录状态）+ Vue Router（网址对应哪一页）**。

### 1.1 根目录：启动与打包用

#### `frontend/package.json`
- **是什么**：前端的「购物清单 + 说明书」。
- **代码含义**：写了项目名、能跑的命令（`dev` / `build` / `preview`）、依赖了哪些库（Vue、Router、Pinia、Element Plus、axios、markdown-it、chart.js 等）。
- **你怎么用**：`npm install` 装依赖，`npm run dev` 开页面。

#### `frontend/package-lock.json`
- **是什么**：把每个库的版本「钉死」，避免不同人电脑装出不一样的结果。
- **代码含义**：超长依赖树，一般不用手改。

#### `frontend/vite.config.ts`
- **是什么**：开发服务器配置。
- **代码含义**：端口 `5173`；把浏览器里的 `/api` 请求**转发**到后端（默认 `http://localhost:8000`）；对流式聊天（SSE）做了特殊头处理。

#### `frontend/index.html`
- **是什么**：浏览器打开时的空壳网页。
- **代码含义**：标题「企业知识库问答」、一个 `<div id="app">`，再引入 `/src/main.ts`。真正内容由 Vue 画进去。

#### `frontend/tsconfig.json` / `tsconfig.app.json` / `tsconfig.node.json`
- **是什么**：TypeScript 编译/检查规则。
- **代码含义**：严格模式、路径别名 `@/` 指向 `src/`；`tsconfig.node.json` 只管 `vite.config.ts`。用户看不到，开发写代码时用。

#### `frontend/Dockerfile`
- **是什么**：用 Docker 跑前端开发服务的配方。
- **代码含义**：基于 `node:22-alpine`，装依赖，暴露 `5173`，执行 `npm run dev`。

#### `frontend/.dockerignore`
- **是什么**：打镜像时忽略 `node_modules`、`dist`，减小体积。

### 1.2 应用入口与全局

#### `frontend/src/main.ts`
- **是什么**：前端程序的**真正起点**。
- **代码含义**：`createApp(App)` → 挂上 Pinia、Router、Element Plus → 引入全局样式 → 执行旧登录态迁移 → 挂到 `#app`。

#### `frontend/src/App.vue`
- **是什么**：最外层组件。
- **代码含义**：几乎只有一个 `<RouterView />`：当前路由是哪页，就显示哪页。

#### `frontend/src/style.css`
- **是什么**：全站基础样式。
- **代码含义**：让页面占满窗口、去掉默认边距、设置中英文字体。

#### `frontend/src/vite-env.d.ts`
- **是什么**：告诉 TypeScript「`.vue` 文件可以 import」。
- **代码含义**：类型声明，无业务逻辑。

#### `frontend/src/shims-markdown-it.d.ts`
- **是什么**：给 `markdown-it` 补类型。
- **代码含义**：方便聊天页渲染 Markdown 时通过类型检查。

---

### 1.3 路由与布局

#### `frontend/src/router/index.ts`
- **是什么**：网址 → 页面的地图，并做登录/权限拦截。
- **代码含义（要点）**：
  - `/login` 登录；`/chat` 问答；`/kbs` 知识库；`/kbs/:id/docs` 文档；`/history` 历史；`/stats` 统计；`/admin/users` 用户管理。
  - `meta.public`：登录页不用 token。
  - `meta.requiresAdmin`：统计、权限管理要管理员。
  - `beforeEach`：没登录去登录页；非管理员不能进后台页。

#### `frontend/src/layouts/MainLayout.vue`
- **是什么**：登录后的「壳」：左侧菜单 + 顶栏 + 中间内容。
- **代码含义**：菜单含智能问答、知识库、历史会话；管理员额外有数据统计、权限管理；顶栏显示用户名、部门、角色、退出；中间是 `<router-view />`。

### 1.4 页面 `views/`（你肉眼能点开的界面）

#### `frontend/src/views/Login.vue`
- **是什么**：登录页。
- **代码含义**：拉部门列表 → 填用户名密码 → 调 `auth.login()` → 跳转（可带回跳地址）。页面上会提示演示账号说明。

#### `frontend/src/views/Chat.vue`
- **是什么**：核心**智能问答**页。
- **代码含义（要点）**：
  - 左侧：选知识库、RAG/Agent 模式、会话列表（新建/置顶/改名/删除）。
  - 右侧：消息列表、引导问题、输入框。
  - `send()` 用 `fetch` 读 **SSE 流**（一段一段出字），事件含 `delta` / `citation` / `tool` 等。
  - 支持 URL 参数带知识库和问题自动开聊。

#### `frontend/src/views/KnowledgeBases.vue`
- **是什么**：知识库列表。
- **代码含义**：表格展示名称/描述/启停；新建、编辑、删除；管理员可配 ACL（谁可读）；点「文档」进文档页；有数量上限提示。

#### `frontend/src/views/Documents.vue`
- **是什么**：某个知识库下的**文档管理**。
- **代码含义**：
  - 上传 PDF/DOCX/TXT/MD；看解析状态、失败原因；下载/重解析/删除。
  - **AI 创作**：填标题和要求 → SSE 流式生成 Markdown → 可改 → 保存入库走解析。
  - 右侧预览切块数、示例问题（可跳问答）；解析中会轮询刷新。

#### `frontend/src/views/History.vue`
- **是什么**：历史会话列表（比聊天侧栏更全）。
- **代码含义**：分页拉会话；打开进 `/chat/:id`；可删除（二次确认）。

#### `frontend/src/views/UploadStats.vue`
- **是什么**：管理员**数据统计**页。
- **代码含义**：文档存量/今日上传/近 7 日趋势；会话存量/今日新建/近 7 日趋势（Chart.js）；超管可看各部门存量。调 `/analytics/uploads`。

#### `frontend/src/views/AdminUsers.vue`
- **是什么**：管理员**用户管理**。
- **代码含义**：搜用户、新建、改角色、启停、删除；看登录时间/历史；保护超级管理员等特殊账号；密码规则校验。

### 1.5 组件 `components/`（页面里复用的小积木）

#### `frontend/src/components/ChatMessage.vue`
- **是什么**：聊天里「一条消息」气泡。
- **代码含义**：用户消息纯文本；助手消息走 Markdown；流式时显示思考/工具调用；下方挂引用来源卡片。

#### `frontend/src/components/StreamMarkdown.vue`
- **是什么**：把 AI 的 Markdown 文案渲染成带格式 HTML。
- **代码含义**：调用 `renderMarkdown`，用 `v-html` 显示（样式管段落、代码块等）。

#### `frontend/src/components/SourceCard.vue`
- **是什么**：一条「引用来源」。
- **代码含义**：文件名、页码/标题、相似度分数；点击展开原文片段。

### 1.6 API 与登录状态

#### `frontend/src/api/http.ts`
- **是什么**：普通接口的统一出口（axios）。
- **代码含义**：`baseURL=/api/v1`；自动带 `Authorization`；业务失败弹错；401 尝试 refresh；防止切账号串 token。聊天 SSE **不走这里**，走 `Chat.vue` 里的 `fetch`。

#### `frontend/src/api/session.ts`
- **是什么**：浏览器里存 token / 用户信息（`sessionStorage`）。
- **代码含义**：读写 access/refresh token、用户缓存；支持从旧版 localStorage 迁移。

#### `frontend/src/stores/auth.ts`
- **是什么**：全局「我是谁」仓库（Pinia）。
- **代码含义**：`login` / `logout` / `loadMe`；计算属性 `isLoggedIn`、`isAdmin`、`isSuperAdmin`；决定菜单和权限判断。

#### `frontend/src/utils/emptyCell.ts`

#### `frontend/src/utils/notifyLimit.ts`

- **代码含义**：`html: false` 关掉原始 HTML，降低 XSS 风险；被 `StreamMarkdown.vue` 使用。

## 二、后端 `backend/`

技术栈可以记成：**FastAPI（接口）+ SQLAlchemy（数据库表）+ Alembic（改表结构）+ Redis（缓存/黑名单）+ Qdrant（向量库）+ 可选 Celery（异步解析）+ 大模型 HTTP 调用**。

### 2.1 项目配置与部署

#### `backend/pyproject.toml`
- **是什么**：后端依赖与工具配置。
- **代码含义**：Python 版本、FastAPI/SQLAlchemy/Qdrant/Celery/LangGraph 等依赖；ruff、pytest 配置。  
  **注意**：默认**不含** `sentence-transformers`，要本地/云上向量模型需另装。

#### `backend/alembic.ini`
- **是什么**：数据库迁移工具配置（脚本目录、日志等）。

#### `backend/alembic/versions/`（迁移脚本）
| 文件 | 小白话 |
|------|--------|
| `0001_initial.py` | 建初始表：部门、用户、知识库、文档、切块、会话、消息、审计等 |
| `0002_conv_pin.py` | 会话增加「置顶」 |
| `0003_feedback_analytics.py` | 消息反馈、行为埋点表 |
| `0004_login_histories.py` | 登录历史表 |
| `0005_platform_super_admin.py` | 支持无部门的平台超级管理员 |

#### `backend/Dockerfile`
- **是什么**：后端镜像配方：Python 3.12 + `uv sync`，跑 `uvicorn` 监听 8000。

---

### 2.2 应用入口

#### `backend/app/main.py`
- **是什么**：后端总开关。
- **代码含义**：创建 FastAPI；启动时检查生产配置、尝试灌 demo 账号；CORS；请求 ID；统一异常格式；挂载 `/api/v1`。

---

### 2.3 `core/` — 地基能力

#### `backend/app/core/config.py`
- **是什么**：从仓库根目录 `.env` 读全部配置。
- **代码含义**：数据库、Redis、Qdrant、`LLM_*` / `DEEPSEEK_*`、Embedding 模型名、上传与数量上限等；`llm_api_key` 等计算属性；生产安全检查。

#### `backend/app/core/deps.py`
- **是什么**：「当前请求是谁登录的」。
- **代码含义**：从 Bearer JWT 解析用户；`require_roles` 限制管理员等角色。

#### `backend/app/core/security.py`
- **是什么**：密码哈希、JWT 签发与解析。

#### `backend/app/core/exceptions.py`
- **是什么**：统一错误包装 `{ code, message, data, request_id }`。

#### `backend/app/core/limits.py`
- **是什么**：读配置里的会话数、知识库数、文档数等上限常量。

#### `backend/app/core/redis.py`
- **是什么**：连 Redis；登出令牌进黑名单、登录失败计数；Redis 挂了有内存兜底。

#### `backend/app/core/logging.py`
- **是什么**：把日志打成 JSON 行，方便排查。

---

### 2.4 `db/` — 数据库

#### `backend/app/db/models.py`
- **是什么**：每张表对应的 Python 类（ORM）。
- **代码含义**：`Tenant`（部门）、`User`、`KnowledgeBase`、`Document`、`Chunk`、`Conversation`、`Message`、ACL、审计、登录历史、埋点等；以及角色/文档状态等枚举。

#### `backend/app/db/session.py`
- **是什么**：异步数据库连接；每个请求拿一个 `Session`。

#### `backend/app/db/base.py`
- **是什么**：导出 ORM 基类，给 Alembic 发现表结构。

#### `backend/app/db/seed.py`
- **是什么**：开发环境自动种演示账号（如超管、部门 admin/user）。仅本地/开发用。

### 2.5 `schemas/` — 接口「填表单」形状

#### `backend/app/schemas/common.py`
- **是什么**：通用响应信封、健康检查数据结构。

#### `backend/app/schemas/dto.py`
- **是什么**：各接口入参/出参模型（自动校验类型、长度）。
- **代码含义**：登录、用户、知识库、文档、会话、聊天、AI 创作文档、反馈、埋点等 DTO。前端传错字段会在这里被拦住。

### 2.6 `api/v1/` — 对外 HTTP 接口（前端主要打这里）

#### `backend/app/api/v1/router.py`
- **是什么**：把下面各个模块的路由拼成一棵树。

#### `backend/app/api/v1/helpers.py`
- **是什么**：成功返回的快捷函数 `ok`、`page_data`。

#### `backend/app/api/v1/health.py`
- **是什么**：探活：分别检查 Postgres / Redis / Qdrant。`GET /health`。

#### `backend/app/api/v1/auth.py`
- **是什么**：登录相关。
- **代码含义**：部门列表、登录、刷新 token、登出、当前用户 `me`、工作区部门；含失败锁定、登录历史。

#### `backend/app/api/v1/users.py`
- **是什么**：管理员用户增删改查、审计日志。

#### `backend/app/api/v1/knowledge_bases.py`
- **是什么**：知识库 CRUD、统计、ACL；创建时同步建 Qdrant 集合。

#### `backend/app/api/v1/documents.py`
- **是什么**：文档上传/列表/下载/删除/重解析/解析预览；上传后触发解析流水线（同步或 Celery）。

#### `backend/app/api/v1/ai_docs.py`
- **是什么**：AI 创作文档：流式生成 + 保存为 `.md` 再入库解析。

#### `backend/app/api/v1/conversations.py`
- **是什么**：会话列表/创建/改标题/删除/搜索/导出/引导问题；可见性按角色过滤（普通用户会话管理者不可见等规则在此）。

#### `backend/app/api/v1/chat.py`
- **是什么**：核心问答 `POST /chat/completions`。
- **代码含义**：RAG：检索 → 拼提示词 → 流式生成 → 存消息与引用；Agent：走多智能体图；无命中时明确说知识库未覆盖。

#### `backend/app/api/v1/tools.py`
- **是什么**：列出 Agent 可用工具白名单。

#### `backend/app/api/v1/analytics.py`
- **是什么**：埋点写入、上传统计看板数据、汇总。供数据统计页等使用。

#### `backend/app/api/v1/system.py`
- **是什么**：只读返回容量阈值、大模型是否已配置（不含密钥）。

### 2.7 `services/` — 真正干活的业务逻辑

#### `backend/app/services/acl.py`
- **是什么**：谁能读/写某个知识库（含超管、管理员、ACL 表）。

#### `backend/app/services/audit.py`
- **是什么**：写审计日志（改角色、删用户等）。

#### `backend/app/services/login_history.py`
- **是什么**：记录登录设备与时间，给用户管理页展示。

#### `backend/app/services/login_lock.py`
- **是什么**：密码错太多次就临时锁账号。

#### `backend/app/services/analytics.py`
- **是什么**：埋点落库；文档/会话 KPI 与近 7 日趋势；超管部门存量汇总。

#### `backend/app/services/storage.py`
- **是什么**：文件存盘、安全文件名、哈希、向量 L2 归一化。

#### `backend/app/services/file_kind.py`
- **是什么**：看文件「魔数」判断真实类型，防止改后缀伪装。

#### `backend/app/services/parsers/__init__.py`
- **是什么**：把 PDF / Word / 文本读成文字块。

#### `backend/app/services/chunker.py`
- **是什么**：长文切成小块（约 800 字）+ 中文分词（给关键词检索用）。

#### `backend/app/services/document_pipeline.py`
- **是什么**：文档流水线总控：解析 → 切块入库 → 向量化 → 写入 Qdrant；状态 `uploaded → parsing → … → ready/failed`。

#### `backend/app/services/embeddings.py`
- **是什么**：文字 → 向量。
- **代码含义**：默认 `sentence_transformers` 加载 `BAAI/bge-m3`；失败则哈希向量降级（能跑但不准）。**用到才加载，不是单独进程。**

#### `backend/app/services/qdrant_store.py`
- **是什么**：对向量库：建集合、写入点、搜索、按文档删除。

#### `backend/app/services/rag_pipeline.py`
- **是什么**：检索总控：向量搜 + 关键词搜 → RRF 融合 → 可选精排。

#### `backend/app/services/rrf.py`
- **是什么**：把两路排名合成一个分数（RRF 算法）。

#### `backend/app/services/rerank.py`
- **是什么**：交叉编码器精排（`bge-reranker`）；没装模型则退回融合分。

#### `backend/app/services/llm_deepseek.py`
- **是什么**：调大模型（OpenAI 兼容 `/chat/completions`）。
- **代码含义**：流式/非流式；系统提示「只根据检索结果答」；没配 Key 用离线占位。默认走云端 DeepSeek，不是本机大模型。

#### `backend/app/services/agent_graph.py`
- **是什么**：Agent 模式：模型在 retrieve / execute / finish 之间循环（LangGraph）。

#### `backend/app/services/ai_document.py`
- **是什么**：拼「AI 创作文档」的提示词（有检索片段要引用；冷启动无片段也允许写草稿并声明）。

#### `backend/app/services/doc_ingest_preview.py`

## 四、两个常混概念（结合本仓库）

1. **向量模型**（`embeddings.py` / 可选 `rerank.py`）  
   - 作用：把文字变成数字，用来「找相似段落」。  
   - 默认在跑后端的那台机器上**按需加载**，不是单独文件夹里的「启动程序」。

2. **大模型 LLM**（`llm_deepseek.py`）  
   - 作用：根据检索结果**写中文回答**、AI 创作、Agent 决策。  
   - 默认 HTTP 调云端（如 DeepSeek）；本仓库源码树里**没有**大模型权重文件。
