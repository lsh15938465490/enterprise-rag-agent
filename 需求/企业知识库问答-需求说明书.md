## 1. 背景与目标

### 1.1 业务背景

企业内部制度、手册、合同、作业指导书分散在 Word/PDF 中。本系统把文档纳入按部门（租户）隔离的知识库，员工用自然语言提问：系统先检索私有资料再生成回答，并展示来源。知识库为空或资料不足时，管理者可用 AI 根据标题与要求生成结构化初稿并入库，降低冷启动成本。

部分问题需要天气、知识库统计等动作，因此提供 **Agent** 模式，在检索之外按步骤调用已开放工具。

### 1.2 产品目标

1. 员工能基于本部门已解析完成的文档问答，回答尽量带来源；无覆盖时明确说明，不编造制度条款。
2. 管理者维护用户、知识库、文档与授权，控制容量。
3. 会话按创建人隔离：普通用户的会话仅自己可见，部门管理者与超级管理员都看不到、打不开。
4. 空库或资料不足时，管理者可通过 AI 生成 Markdown 初稿，编辑确认后入库成为可检索文档。
5. 未配置大模型密钥时检索仍可发生，生成为离线占位，业务上需告知。

### 1.3 成功标准

- 约定账号可登录；普通用户看不到「权限管理」「上传统计」。
- 上传或 AI 保存的文档进入 `ready` 后可被问答命中。
- 知识库无覆盖时提示未覆盖，不编造条款。
- 容量超限、同名文件、后缀与文件头不一致时有明确提示且不写库。
- `adminliu` 不可降为普通用户、不可禁用、不可删除。
- AI 创作：有检索片段时正文带来源编号；空库可冷启动生成并声明需人工核对；保存后走与上传相同的解析流水线。

## 3. 用户、租户与权限

### 3.1 租户（部门）

数据按租户隔离。登录页**必须选择部门**（演示：部门01 slug `demo`，部门02 slug `acme`）。

平台超级管理员 `adminliu`：`tenant_id` 为空，登录时不校验所选部门；可在知识库/文档等页切换所属租户；历史会话、用户列表可见租户列。

### 3.2 角色

| 业务称呼 | 系统角色 | 说明 |
|---|---|---|
| 最高管理者 / 超级管理员 | `super_admin` | 固定账号 **adminliu**。跨租户；不能改为其他角色、不能禁用、不能删除 |
| 管理者 | `tenant_admin` | 本部门用户、知识库、文档、ACL、上传统计 |
| 普通用户 | `member` | 问答、查看已授权知识库与文档、仅自己的历史会话 |

开发/演示密码均为 `Admin@123456`（仅非生产种子数据）：

- 超管：`adminliu`
- 部门01：`admin01` / `user01`
- 部门02：`admin02` / `user02`

### 3.3 菜单与操作

| 能力 | 普通用户 | 部门管理者 | 超级管理员 |
|---|---|---|---|
| 智能问答 | 有 | 有 | 有 |
| 知识库列表、文档查看/下载 | 仅 ACL 可读且启用的库 | 本部门 ACL 可读（含停用库管理） | 全部 |
| 知识库新建/停用/删除/ACL | 无 | 本部门 | 跨部门 |
| 文档上传 / AI 创作 / 重解析 / 删除 | 无 | 对本部门有写权限的库 | 有 |
| 历史会话 | 仅自己 | 本部门管理者会话 | 各管理者会话，含租户列 |
| 上传统计 | 无 | 有 | 有 |
| 权限管理 | 无（直链回问答） | 本部门用户 | 全部用户 |

### 3.4 会话可见性

- 普通用户：只展示、只打开自己新建的会话；猜到他人会话 ID 也按不存在处理。
- 部门管理者：只看本部门**管理者**自己的会话；**看不到、打不开**普通用户的会话。
- 超级管理员：可看各租户的**管理者**会话（含租户列）；**看不到、打不开**普通用户的会话。

### 3.5 知识库可见性与 ACL

- **超级管理员**：默认可读全部库；可给该部门**除超管外的所有用户**配置「可读」（含部门管理者）。保存 ACL **只覆盖其管辖范围内的条目**，不抹掉部门管理员给普通用户配过的授权。
- **部门管理员**：列表以 **ACL 可读**为准（取消可读后立刻从列表消失，不再因「创建人」绕过）。ACL 弹窗只能给本部门**普通用户**开/关可读，不能改其他管理者的授权。
- **普通用户**：仅 ACL 可读且库为启用状态；停用库不出现在问答选库中，已绑定会话检索时也会滤掉停用库。
- 写权限：仅管理者（及超管）；普通用户不能上传、AI 创作、改 ACL。

### 3.6 角色变更约束

- 不能通过界面再创建另一个超级管理员。
- 部门管理员**不能修改自己的角色**；可把本部门普通用户改为管理者或改回普通用户。
- 仅超级管理员可调整管理者角色（除上述自我修改禁令外的平台规则以接口为准）。
- 不能删除当前登录账号。

## 4. 功能需求

未满足前置时，操作应失败或按钮不可用，并给出业务可理解的提示。

### FR-01 登录与退出

1. 打开登录页，选择部门，输入用户名、密码（不预填密码）。
2. 成功进入智能问答；失败统一「用户名或密码错误」，不区分账号是否存在。
3. 连续多次密码错误会锁定一段时间（默认约 5 次 / 5 分钟），前端仍用同一失败文案。
4. 刷新保持登录；退出清除当前标签登录态。
5. **同一浏览器多个标签可分别登录不同账号**（`sessionStorage`，避免 localStorage 串号）。
6. 未登录访问内部页跳转登录。
7. 停用账号无法登录。

### FR-02 权限管理

1. 侧栏「权限管理」仅管理者可见。
2. 搜索、新建（用户名、邮箱、密码、角色）。
3. 角色：普通用户 / 管理者；启用/禁用。超管行角色不可降、不可禁。
4. 表格展示最近登录时间；多次登录时悬停可看时间与设备；空值显示 `--`。
5. 超管列表可看「部门」列。
6. 密码至少 8 位且同时含字母和数字；租户内用户名、邮箱不重复。
7. 角色/启用变更写入审计日志（接口可查，页面无独立审计菜单）。

### FR-03 知识库管理

1. 新建：名称、描述；空描述列表显示 `--`，可事后编辑。
2. 启用/停用、删除（策略以现网为准）。
3. 租户内启用中知识库最多 **10** 个（可配置）；名称租户内不重复。
4. 文档页可切换所属租户（仅超管下拉可用）。

### FR-04 文档管理

1. 管理者点击「上传文件（剩余上传数量 N）」打开方式弹窗。
2. **上传 PDF/DOCX/TXT/MD**：支持一次多选，走批量接口；单文件默认最大 50MB（可配置）；每库最多 **5** 份（可配置，含 AI 保存的文档）。
3. **同一知识库文件名不可重复**。
4. **文件头须与后缀一致**：PDF 以 `%PDF` 开头；DOCX 为 ZIP 且含 `word/document.xml`；TXT/MD 不得为 PDF/ZIP/可执行文件/OLE。
5. 流水：上传 → 解析 → 切块 → 向量化 → `ready` 或失败；列表约 3 秒刷新；可下载、重解析、删除。
6. 选中文档右侧展示切块数与 Agent 示例问题（可跳转问答）。
7. 普通用户只看列表和下载。

### FR-08 AI 创作（说明书 03，已落地）

**作为** 知识库管理者  
**我想要** 按标题和内容要求生成结构化文档初稿  
**以便** 空库冷启动或基于已有资料快速成文

**入口**：文档列表 →「上传文件（剩余上传数量 N）」→「AI 创作」（库已满时不可用）。

**流程**

1. 填写「文档标题」「内容要求/描述」。
2. 系统以标题+要求在**当前知识库**做向量+关键词检索（Top-K 片段）。
3. 拼装 Prompt，要求模型输出 Markdown，结构包含：**文档概述、核心章节、具体要点、引用来源**。
4. **SSE 流式**展示正文；有命中时列出与 `[S1][S2]` 对应的来源（文件名、页码、标题）。
5. 用户可编辑正文后点「保存入库」：存为 `{标题}.md`，进入与上传相同的解析流水线，成为可检索文档。

**规则**

- 仅管理者可调用；普通用户 403。
- **冷启动**：无检索片段时仍生成初稿，须声明「当前知识库暂无参考片段，需人工核对」，不得伪造本企业未给出的制度数字。
- **有库**：关键事实应引用检索片段编号。
- 保存占用该库文档名额；超限或与已有文件名冲突则拒绝。
- 模型使用现有 LLM 配置（OpenAI 兼容 / DeepSeek 等），密钥未配置时为离线占位稿。

**接口**（挂在现有 `/api/v1` 前缀下，对应需求中的 generate-document）：

- `POST /api/v1/ai/generate-document`  
  参数：`knowledge_base_id`、`title`、`requirements`、`stream`（默认 true）
- `POST /api/v1/ai/save-document`  
  参数：`knowledge_base_id`、`title`、`content`

### FR-05 新建会话与问答

1. 选择一个或多个**启用且当前用户可读**的知识库，选 RAG 或 Agent，新建会话。
2. 选中后下拉收起；新建成功后勾选清空。
3. 每账号最多 **20** 个会话（可配置）。智能问答侧栏只展示**近 7 天内有活动**且最近更新的最多 **10** 个会话；超过 7 天未问答的会话只出现在「历史会话」。
4. 空会话展示最多 3 条引导问题；无就绪文档时说明暂不可生成。
5. 发送后滚到最新消息；出字前可显示等待态。
6. **RAG**：检索后生成；来源卡片；不足则「当前知识库未覆盖该问题」。
7. **Agent**：可 retrieve 或调用工具（天气、知识库统计；只读 SQL 默认关）；过程条仅生成中展示。
8. 会话：置顶、重命名、删除（二次确认）。

后端另有点赞/点踩存储、会话导出、会话搜索接口，**前端无对应按钮**。

### FR-06 历史会话

范围与侧栏可见身份一致：普通用户只看自己的会话；部门管理者与超级管理员都**不能**看到普通用户的会话。本页展示该范围内**全部**会话（含超过 7 天未活动的）；智能问答侧栏仅近 7 天内最近 10 个。点击进入原会话。超管显示租户列。空单元格 `--`。

### FR-07 容量与提示

| 对象 | 默认上限 | 超限 |
|---|---|---|
| 每用户会话 | 20 | 提示约 3 秒，接口拒绝；问答页侧栏只列近 7 天内最近 10 个 |
| 租户启用中知识库 | 10 | 同上 |
| 每知识库文档（含 AI 保存） | 5 | 同上 |
| 同名文档 | 不允许 | 提示改名 |
| 单文件大小 | 50MB | 提示 |
| 文件头与后缀 | 必须一致 | 提示「文件内容与后缀不一致」 |

上限可在后端配置调整，无需改业务代码。

### FR-09 上传统计

管理者侧栏「上传统计」：文档存量/可检索/处理失败/今日上传与近 7 日上传趋势；**新建会话**存量、今日新建、近 7 日新建及趋势。超级管理员另见各部门文档与会话存量。时间按北京时区。范围随当前登录身份（本部门 / 超管全局）。

## 5. 关键业务规则

1. **租户隔离**：业务数据按部门隔离；超管为平台账号，可跨租户运维。
2. **答案依据**：制度类问题以检索为准，无依据不编造。
3. **停用库**：不进入问答选库，不参与检索。
4. **模型**：生成依赖已配置的兼容接口；变更需重启后端后生效。
5. **表格空值**：统一显示 `--`。
6. **审计**：问答带来源；权限变更有后端日志；完整审计页不作为本期前端验收项。

## 7. 主流程（培训）

### 7.1 把资料变成可问

登录部门管理者 → 知识库新建 → 进入文档 → 上传或 AI 创作保存 → 等待 `ready` → 问答勾选该库 → 新建会话 → 提问。

### 7.2 普通用户只问不改库

登录普通用户 → 只能看到被授予可读的启用库 → 新建会话提问。无权限管理、上传统计、上传与 AI 创作。

### 7.3 空库冷启动

文档页 → AI 创作 → 填标题与要求 → 生成初稿并人工核对 → 保存入库 → 解析完成后即可问答。

### 7.4 模式选择

- **RAG**：查制度、手册、合同条款。
- **Agent**：天气、库内文档数量等需工具的问题。

## 8. 异常与提示

| 场景 | 结果 |
|---|---|
| 用户名或密码错误 / 锁定中 | 不说明具体原因 |
| 未登录 | 回登录页 |
| 无写权限 | 无按钮或 403 |
| 知识库未覆盖 | 明确未覆盖 |
| 模型失败 | 模型调用失败类提示 |
| 未配密钥 | 检索可进行，生成为占位 |
| 超限 / 同名 / 文件头不符 | 约 3 秒提示，不写库 |
| AI 保存时库已满 | 提示先删除再保存 |

- [ ] 多选上传、剩余数量、同名、50MB、文件头校验生效。
- [ ] AI 创作流式出字；有库时有来源；空库冷启动声明；保存后出现在文档列表并进入解析。
- [ ] 会话 20、知识库 10、文档 5 拦截生效；智能问答侧栏最多 10 条且仅为近 7 天活跃会话，历史会话为全部。
- [ ] RAG 来源卡片；无命中说未覆盖。
- [ ] 历史会话：普通用户会话仅自己可见；`admin01`/`adminliu` 列表中无 `user01` 的对话，直链打开按不存在处理。超管可见租户列。
- [ ] 上传统计页管理者可见、数字与库内文档大致相符。
- [ ] 空描述、空单元格显示 `--`。
- [ ] 部门管理员不能改自己的角色。
