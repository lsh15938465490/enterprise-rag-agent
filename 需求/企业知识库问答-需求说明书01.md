# 企业知识库问答平台 — 业务需求说明书

| 项 | 内容 |
|---|---|
| 文档名称 | 企业知识库问答平台业务需求说明书 |
| 文档性质 | 按**当前已实现系统**整理的需求基线，供验收、培训、后续迭代对齐 |
| 适用产品 | 企业内部知识库问答（RAG + Agent） |
| 读者 | 产品、业务、测试、实施、研发 |
| 整理口径 | 以仓库现网代码与页面行为为准，不以早期设计稿中未落地能力为准 |

---

## 1. 背景与目标

### 1.1 业务背景

企业内部制度、手册、合同、作业指导书分散在 Word/PDF 中，员工提问常依赖「问同事、翻共享盘」。本系统把文档纳入知识库，员工用自然语言提问，系统先检索私有资料再生成回答，并展示来源，降低答非所问和口头传错的风险。

部分问题不只是「查文档」，还可能涉及天气查询、知识库统计等动作，因此提供 **Agent（智能体）** 模式，在检索之外允许按步骤调用已开放的工具。

### 1.2 产品目标

1. 员工能基于本企业已上传、已解析完成的文档进行问答，回答尽量带来源。
2. 管理者能维护用户、知识库和文档，控制容量，避免库无限膨胀。
3. 普通用户与管理者的会话互相隔离：普通用户只看到自己建的对话；管理者能看到全部对话并区分创建人类型。
4. 未配置大模型密钥时，检索仍可发生，但生成质量受限（占位/离线逻辑），业务上需明确告知。

### 1.3 成功标准（业务可验收）

- 使用约定账号可登录；普通用户看不到「权限管理」。
- 上传支持的文档后，状态变为可检索（ready）即可被问答命中。
- 知识库无覆盖时，系统明确提示未覆盖，而不是编造制度条款。
- 容量超限、同名文件时，有明确提示且不会写库。
- 最高管理者账号不可被降为普通用户、不可被禁用。

## 2. 范围说明

### 2.1 本期范围（In Scope）

| 模块 | 业务范围 |
|---|---|
| 登录与会话 | 账号密码登录、保持登录、退出 |
| 权限 | 最高管理者 / 管理者 / 普通用户；菜单与操作差异 |
| 知识库 | 创建、启用/停用、列表、授权（ACL，管理者） |
| 文档 | 上传、状态查看、下载、重新解析、删除 |
| 智能问答 | 新建会话、RAG/Agent、流式回答、来源卡片、引导问题 |
| 历史会话 | 列表进入原会话继续聊 |
| 容量与校验 | 会话/知识库/文档数量上限、同名文档拦截 |

### 2.2 本期不做（Out of Scope）

- 单点登录（SSO/LDAP）、短信验证码、扫码登录
- 图片/扫描件 OCR、表格专项解析
- 文档字段级（某一段）权限，仅到知识库读写授权
- 自建大模型训练、微调
- 公有云多租户自助开户（界面不填租户，开发环境固定演示租户 `demo`）

## 3. 用户与权限

### 3.1 角色定义

业务上对外只强调两类常用身份，系统内部另保留「最高管理者」保护位。

| 业务称呼 | 系统角色 | 说明 |
|---|---|---|
| 最高管理者 | `super_admin` | 账号固定为 **adminliu**。拥有管理者全部能力，且**不能改为普通用户、不能禁用**。 |
| 管理者 | `tenant_admin`（权限管理里可选） | 可做用户管理、知识库维护、文档上传删除。 |
| 普通用户 | `member` | 问答、查看知识库与文档、看自己的历史会话。不能进权限管理，不能改知识库/上传删除文档。 |

开发环境预置账号（密码均为 `Admin@123456`，仅非生产环境自动写入）：

- 最高管理者：`adminliu`
- 普通用户：`user`

### 3.2 菜单与操作对照

| 能力 | 普通用户 | 管理者 / 最高管理者 |
|---|---|---|
| 智能问答 | 有 | 有 |
| 知识库列表、查看文档、下载 | 有 | 有 |
| 知识库新建 / 停用 / 删除 / ACL | 无 | 有 |
| 文档上传 / 重新解析 / 删除 | 无 | 有 |
| 历史会话 | 仅自己的会话 | 本租户全部会话 |
| 权限管理（用户增删改角色） | 无，直接访问会回到问答页 | 有 |

### 3.3 会话可见性（重点规则）

- 普通用户：只展示、只打开**自己新建**的会话；管理者建的会话不出现在其列表中。
- 管理者 / 最高管理者：展示本租户**全部**会话；每条会话用标签区分「最高管理者 / 管理者 / 普通用户」创建。
- 普通用户即使猜到别人会话的地址，也打不开（按不存在处理）。

### 3.4 知识库可见性

同一租户内**已启用**的知识库，普通用户与管理者均可在问答中勾选、均可在知识库页查看（只读操作对普通用户开放）。停用库普通用户不再用于问答列表。

## 4. 功能需求

说明：下列「前置」未满足时，对应操作应失败或不可点，并给出业务可理解的提示。

---

### FR-01 登录与退出

**作为** 任意员工  
**我想要** 用账号密码进入系统  
**以便** 使用问答和知识库

**流程**

1. 打开登录页，输入用户名、密码（不展示租户输入框；后台固定走演示租户）。
2. 用户名、密码均需自行填写，不预填密码。
3. 登录成功进入智能问答；失败统一提示「用户名或密码错误」，不区分是账号不存在还是密码错。
4. 刷新浏览器保持登录；点退出清除登录态并回到登录页。
5. 未登录访问内部页，跳转登录。

**规则**

- 停用账号无法登录。
- 登录页可展示开发环境演示账号提示（灰色小字），便于实施验收，生产环境不应依赖该提示作为安全策略。

---

### FR-02 权限管理

**作为** 管理者  
**我想要** 维护本企业账号  
**以便** 控制谁能登录、谁是管理者

**流程**

1. 侧栏进入「权限管理」（仅管理者可见）。
2. 可按用户名/邮箱搜索，新建用户（用户名、邮箱、密码、角色）。
3. 可将账号设为「普通用户」或「管理者」，可启用/禁用。
4. `adminliu`（最高管理者）角色下拉禁用，操作列显示不可降级；接口拒绝降级与禁用。

**规则**

- 密码需至少 8 位且同时包含字母和数字。
- 同一租户内用户名、邮箱不可重复。
- 不能通过界面创建另一个「最高管理者」账号。
- 普通用户访问该路由时被送回问答页。

---

### FR-03 知识库管理

**作为** 管理者  
**我想要** 建立和维护知识库  
**以便** 把一类资料圈在一起供问答使用

**流程**

1. 进入「知识库」，点新建，填写名称、描述。
2. 列表展示名称、描述、是否启用。
3. 可停用/启用、软删除（停用，不物理清空历史文件策略以现网为准）。
4. 可为知识库配置 ACL（指定本租户用户可读/可写）；普通用户无此入口。

**规则**

- 租户内**启用中**的知识库最多 **10** 个。超限点「新建」弹出提示，约 **3 秒**后消失，前后端均拦截。
- 停用后腾出名额，才可再新建。
- 知识库名称在租户内不可重复。

---

### FR-04 文档管理

**作为** 管理者  
**我想要** 向某个知识库上传资料  
**以便** 问答能检索到正文

**流程**

1. 从知识库进入文档页。
2. 上传 PDF / Word（docx）/ TXT / MD，单文件大小受系统配置限制（默认 50MB）。
3. 上传后文档进入处理流水：上传 → 解析 → 切块 → 向量化 → **ready（可检索）** 或失败。
4. 处理中列表约每 3 秒刷新；失败展示原因；可重新解析、下载、删除。
5. 普通用户可查看列表、下载，不能上传/删除/重新解析。

**规则**

- 每个知识库最多 **5** 份文档。超限提示约 3 秒后消失，前后端拦截。
- **同一知识库不允许相同文件名**。提示文案：「已经有相同名字的文档，请修改名字后重新上传」。
- 仅 **ready** 的文档参与问答检索。未解析完成就提问，可能显示知识库未覆盖或检索偏弱。

---

### FR-05 新建会话与问答（核心）

**作为** 已登录用户  
**我想要** 选知识库后提问  
**以便** 得到基于资料的回答

#### 5.1 新建会话

1. 在智能问答页选择一个或多个知识库、选择模式（RAG 或 Agent），点「新建会话」。
2. 选中知识库后下拉立即收起，避免挡住按钮；仍支持再打开继续多选。
3. **新建成功后，知识库勾选清空**，不记住上次选择，下次必须重选。
4. 每个账号最多 **10** 个会话。超限点新建会提示（约 3 秒），前后端拦截。删除会话后可再新建。
5. 未选知识库时提示至少选一个。

#### 5.2 空会话引导

会话已创建、尚未发送任何问题时，中间展示「你可以试着问」及最多 **3** 条引导问题（根据该会话绑定知识库中已就绪文档生成）。点击某条即作为问题发出。无就绪文档时说明暂不可生成引导问题。

#### 5.3 提问与展示

1. 输入问题，Enter 或点发送。
2. 发送后右侧对话区**自动滚到最底部**，始终对着最新内容。
3. 助手尚未吐字时，在助手区域显示 **think...**；开始出字后消失。
4. **RAG 模式**：先检索绑定知识库，再按检索片段生成回答；底部展示来源卡片（文件名、摘要、相关分等）。检索不足时明确「当前知识库未覆盖该问题」。
5. **Agent 模式**：模型可分步决定检索或调用工具（如天气、知识库统计；只读 SQL 默认关闭）。过程中可出现灰色过程条（调度/检索进行中）；**完整回答输出后灰色过程条不再展示**，只保留正文和来源。
6. 历史气泡不因后来配置了模型密钥而自动改写；要新答案需再问一次或新开会话。

#### 5.4 会话操作（列表）

鼠标移到会话上的「···」即弹出菜单（无需点击）：

- 置顶 / 取消置顶（置顶排在列表上方）
- 重命名
- 删除（二次确认，删除后消息不可恢复；若删的是当前打开的会话，回到未选会话状态）

管理者列表额外展示创建人类型标签。

---

### FR-06 历史会话

**作为** 用户  
**我想要** 从历史入口找回对话  
**以便** 继续问或复核当时的回答

**规则**

- 数据范围与智能问答侧栏一致：普通用户仅自己的会话；管理者看全部，并显示创建人类型。
- 点击一行进入对应会话。

---

### FR-07 容量与提示（横切）

| 对象 | 上限 | 超限表现 |
|---|---|---|
| 每用户会话 | 10 | 点新建会话提示，约 3 秒关闭；接口拒绝 |
| 租户启用中知识库 | 10 | 点新建知识库提示；接口拒绝 |
| 每知识库文档 | 5 | 点上传提示；接口拒绝 |
| 同名文档 | 不允许 | 提示修改名字后重传 |

提示形态为右上角通知类弹层，时长约 3 秒。

## 5. 关键业务规则汇总

1. **租户隔离**：业务数据按企业（租户）隔离；当前界面不让用户填租户，开发环境使用 `demo`。
2. **答案依据**：制度类问题应以知识库检索结果为准，禁止系统在无依据时编造条款、数字。
3. **引用**：有检索命中时应能对应到来源文档片段，便于业务核对原文。
4. **模型依赖**：生成通顺中文回答依赖已配置的 DeepSeek 接口密钥；未配置时检索可进行，回答可能为占位说明。密钥变更需重启后端服务后生效（配置启动时加载）。
5. **会话归属**：以创建人账号为准，不随后续角色变更自动转让（角色变更后的列表规则仍按当前角色 + 原创建人计算展示标签）。
6. **软删除知识库**：停用后普通用户侧不再作为启用库使用；名额按启用中数量计算。

## 6. 非功能需求（业务侧关注点）

| 类型 | 要求 |
|---|---|
| 安全 | 密码不明文存储；接口需登录；失败提示不暴露「用户是否存在」；生产环境禁止默认库口令和默认密钥。 |
| 可用性 | 文档解析较慢时应有状态，而不是让用户以为上传失败。问答为流式输出，减少长时间白屏。 |
| 容量 | 见 FR-07，防止演示/小团队环境被刷爆。 |
| 审计可追溯 | 问答带来源；Agent 过程在生成中可见。完整审计日志若未作为独立页面提供，不作为本期验收项。 |
| 兼容 | 桌面浏览器使用（Chrome 等）；管理端表单/表格操作为主。 |

## 7. 主流程（给实施/培训用）

### 7.1 管理者把资料变成可问

登录 `adminliu` → 知识库新建 → 进入文档 → 上传文件 → 等待状态 `ready` → 智能问答勾选该库 → 新建会话 → 提问或点引导问题。

### 7.2 普通用户只问不改库

登录 `user` → 智能问答勾选已有库 → 新建会话 → 提问。看不到权限管理，不能上传文档，看不到管理者建的会话。

### 7.3 两种问答模式怎么选

- **RAG**：问「制度怎么规定、公司名称是什么」等查资料问题。
- **Agent**：可能要查天气、看库里有多少文档、或多步先检索再作答。过程条仅生成中展示。

## 8. 异常与提示（业务口径）

| 场景 | 用户应看到的结果 |
|---|---|
| 用户名或密码错误 | 不说明具体是哪一项错 |
| 未登录 | 回到登录 |
| 无权限改知识库 | 无按钮或提示无权限 |
| 知识库未覆盖 | 明确未覆盖，不编造 |
| 模型不可用 | 模型调用失败类提示，而非「未配置」占位（已配置密钥但仍失败时） |
| 未配模型密钥 | 可检索，回答可能提示未配置密钥（离线占位） |
| 超限 / 同名文件 | 3 秒提示，数据不增加 |

## 9. 验收清单（测试可直接打勾）

- [ ] `adminliu` 可登录，顶栏为最高管理者，有权限管理；角色不能改为普通用户、不能禁用。
- [ ] `user` 可登录，无权限管理；能看到启用中的知识库并问答；不能上传文档。
- [ ] `user` 列表中无 `adminliu` 新建的会话；`adminliu` 能看到双方会话及创建人标签。
- [ ] 新建会话成功后知识库选择被清空。
- [ ] 勾选知识库后下拉关闭。
- [ ] 空会话展示最多 3 条引导问题（有就绪文档时）。
- [ ] 发送后页面滚到最新消息；回答前有 think...。
- [ ] Agent 过程灰条在全文结束后消失。
- [ ] 会话 10、知识库 10、文档 5、同名文件四类拦截生效。
- [ ] RAG 有来源卡片；无命中时说未覆盖。
- [ ] 历史会话与侧栏可见范围一致。

## 10. 术语表

| 术语 | 含义 |
|---|---|
| 知识库 | 一类资料的容器，问答时必须指定范围 |
| 切块 | 把长文档切成小段，检索和引用针对小段 |
| 向量检索 | 按语义相近查找片段，不是只按关键字 |
| RAG | 先检索再生成，路径固定 |
| Agent | 模型可多步选择检索或工具后再给出最终回答 |
| 租户 | 企业隔离单位；当前界面不展示填写项 |
