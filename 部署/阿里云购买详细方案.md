# 阿里云购买详细方案（一台/两台装项目）

> 面向小白：按步骤在阿里云买服务器，用来部署本仓库「企业知识库问答」以及后续其它项目。  
> 价格会随活动变化，以下为选购思路；下单以控制台实时价为准。

---

## 一、买之前先想清楚买几台

### 推荐组合（最稳妥）

| 机器 | 用途 | 建议规格 | 月费量级（参考） |
|------|------|----------|------------------|
| **服务器 A** | 只部署本 RAG 项目（前端+后端+PG+Redis+Qdrant） | **4核 8G**，系统盘 ≥ 80G，带宽按套餐 | 约 **90～220 元/月**（常见约 100 元档） |
| **服务器 B**（可选，以后再买也行） | 另外 3 个偏轻的项目 | **2核 4G** 或 **4核 8G** | 约 **30～100 元/月** |

### 若坚持只买一台

- 本项目 + 另外 3 个都较轻 → 选 **4核 16G**
- 只有本项目、另外三个以后再说 → 先买 **4核 8G** 即可

### 计费方式建议

| 方式 | 适合谁 |
|------|--------|
| **按月** | 你说的「按月续费」，灵活，可随时降配/释放 |
| **按年** | 更便宜，适合确定长期用 |

个人/演示优先：**轻量应用服务器**（比云服务器 ECS 更好上手，带宽套餐简单）。

## 二、注册与实名（第一次必做）

### 步骤 1：打开官网

浏览器打开：[https://www.aliyun.com](https://www.aliyun.com)

### 步骤 2：注册账号

1. 点击右上角 **免费注册 / 登录**  
2. 用手机号注册（或已有阿里云账号直接登录）  
3. 设置登录密码，完成验证码

### 步骤 3：实名认证（不认证一般买不了国内服务器）

1. 登录后进入 **账号中心 → 实名认证**  
2. 个人用户：支付宝扫码或上传身份证（按页面提示）  
3. 等待通过（通常很快）

### 步骤 4：（可选）领优惠券 / 看活动

1. 打开阿里云「优惠」或「轻量应用服务器」活动页  
2. 新用户常有秒杀/券，**先领券再下单**更便宜  
3. 学生可看「云翼计划」等（有资格再弄）

## 三、购买服务器 A（跑本 RAG 项目）— 逐步点击

### 步骤 1：进入轻量应用服务器购买页

任选一种方式：

- 官网搜索：**轻量应用服务器**  
- 或打开产品页后点 **立即购买**  
- 控制台路径大致：  
  **登录控制台 → 产品与服务 → 轻量应用服务器 → 创建服务器 / 立即购买**

> 若活动页只有「云服务器 ECS」，也可以买 ECS，下面「配置怎么选」同样适用，只是安全组要多点几步。

### 步骤 2：选地域（很重要）

| 项 | 建议 |
|----|------|
| 地域 | 选离你或用户近的，如 **华东1（杭州）**、**华北2（北京）**、**华南1（深圳）** |
| 注意 | **买完不能直接改地域**；以后备份迁移才换得了 |
| 多台时 | 两台尽量同一地域，延迟更低（本方案两台也可同地域） |

### 步骤 3：选套餐/实例规格

在套餐列表里找：

1. **CPU：4 核**  
2. **内存：8 GB**（只装本项目；若还要硬塞另外三个轻项目，更稳选 **16 GB**）  
3. **系统盘：约 70～100 GB ESSD**（够用即可，太小以后扩容也行但麻烦）  
4. **带宽**：轻量多为峰值带宽套餐，按页面套餐选，一般够演示  

计费：**按月**（你要按月续费就选月付）。

### 步骤 4：选镜像（系统）

1. 镜像类型选 **系统镜像**（或「纯净版」）  
2. 操作系统选：**Ubuntu 22.04**（推荐）或 Ubuntu 20.04  
3. **不要**一上来选「WordPress / 宝塔」等应用镜像（除非你很熟宝塔；本项目用 Docker 更干净）

> 若你更熟 CentOS，可选 Alibaba Cloud Linux / CentOS 兼容版，但文档命令以 Ubuntu 为例。

### 步骤 5：设置密码或密钥

两种方式二选一：

**方式 A（小白简单）：设置 root/登录密码**

1. 选 **密码**  
2. 设一个强密码（大小写+数字+符号），**记到密码本**，不要用 `123456`  
3. 以后用 SSH 或网页远程桌面登录

**方式 B（更安全）：SSH 密钥对**

1. 创建密钥对并下载 `.pem` 私钥  
2. 私钥只保存一份，丢了很难再进服务器  

演示阶段用 **密码** 即可。

### 步骤 6：主机名与数量

- 实例名称可填：`rag-prod` 或 `enterprise-rag`  
- 购买数量：**1**  
- （可选）到期自动续费：按月用可先打开，避免忘续费停机

### 步骤 7：确认订单并支付

1. 核对：地域、4核8G、Ubuntu、时长 **1 个月**  
2. 有券就勾选优惠券  
3. 同意服务协议 → **确认订单 / 支付**  
4. 支付成功后，到控制台看状态变为 **运行中**

### 步骤 8：记下这些信息（后面部署要用）

在实例详情页抄下来：

| 信息 | 写在哪里 |
|------|----------|
| 公网 IP | 例如 `47.x.x.x` |
| 地域 | 例如华东1 |
| 登录用户名 | Ubuntu 常见 `root`（有的是 `ubuntu`，看控制台说明） |
| 密码或密钥 | 自己保存 |
| 内网 IP | 同地域多机互通时用 |

## 四、防火墙 / 安全组怎么开端口

轻量应用服务器一般在实例页有 **防火墙**。

### 本项目演示阶段建议放行

| 端口 | 用途 | 是否长期开 |
|------|------|------------|
| **22** | SSH 远程登录 | 要开（可限制只你自己 IP） |
| **80** | HTTP（以后 Nginx） | 建议开 |
| **443** | HTTPS | 有域名证书后开 |
| **8000** | 后端 API（临时演示） | 可临时开，上 Nginx 后可关 |
| **5173** | 前端开发服（临时） | 可临时开，生产改静态后关 |

### 不要对公网开放（很重要）

| 端口 | 服务 | 原因 |
|------|------|------|
| 5432 | PostgreSQL | 会被扫库爆破 |
| 6379 | Redis | 同上 |
| 6333/6334 | Qdrant | 同上 |

这些只在 Docker 内部互通即可。

### 操作方法（轻量）

1. 控制台 → 你的实例 → **防火墙**  
2. **添加规则** → 分别加 22/80/443（以及临时 8000、5173）  
3. 策略：允许，协议 TCP，来源可先 `0.0.0.0/0`（以后可改成仅自己办公网 IP）

若买的是 **ECS**：到 **安全组 → 入方向** 添加同样规则。

## 五、第一次登录服务器（验证买成功）

### Windows 上推荐

1. 安装 **Windows Terminal** 或使用 PowerShell  
2. 执行（把 IP、用户换成你的）：

```powershell
ssh root@你的公网IP
```

3. 第一次提示指纹输入 `yes`  
4. 输入购买时设的密码（输入时不一定显示字符，属正常）

能看到 Linux 命令行提示符，说明机器到手。

### 网页方式（不会 SSH 时）

轻量控制台常有 **远程连接**，用浏览器登进桌面/终端，同样能操作。

## 六、买完机器后还要不要买别的？

| 产品 | 现在要不要买 |
|------|----------------|
| 云服务器（上面已买） | ✅ 要 |
| 云数据库 RDS | ❌ 先不要（库装在 Docker 里更省） |
| 云 Redis | ❌ 先不要 |
| 对象存储 OSS | ❌ 先不要 |
| 域名 | 可选：要有 `xxx.com` 再买 |
| SSL 证书 | 有域名后用免费证书即可 |
| GPU 云服务器 | ❌ 不要（大模型用 API） |

### 域名怎么买（可选）

1. 阿里云 → **域名** → 搜索想要的名字 → 加入清单结算  
2. 实名认证域名（国内域名要备案才能用 80/443 解析到国内服务器）  
3. **重要：**  
   - 域名解析到**国内**服务器 → 一般要做 **ICP 备案**（要花几天到几周）  
   - 不想备案：可用 **公网 IP 访问**，或域名解析到**香港等境外**地域（规则以阿里云当前政策为准）

个人演示阶段：**直接用 `http://公网IP:5173` 即可**，域名后补。

## 七、服务器 B（另外三个项目）怎么买

等本项目部署稳定后再买也行，步骤与上面几乎一样：

1. 再进 **轻量应用服务器 → 创建**  
2. 地域与 A **相同**  
3. 规格：三个项目都轻 → **2核 4G**；偏重 → **4核 8G**  
4. 镜像同样 **Ubuntu 22.04**  
5. 防火墙同样开 22/80/443  
6. 名称可叫 `apps-other`

两台用不同公网 IP；各自 Nginx 绑不同域名，或同一域名不同子域名。

## 八、支付与续费（按月）

### 月付怎么续

1. 控制台 → 费用中心 / 轻量实例 → **续费**  
2. 可勾选 **自动续费**（绑支付宝/信用卡），避免到期停机  
3. 到期未续费：实例可能停机，数据短期常还在，但有释放风险，**别拖太久**

### 钱不够时

- 先释放不需要的临时端口服务  
- 不要用 `docker compose down -v`（会删数据卷）  
- 降配有限制，轻量套餐有的不能任意改，以控制台为准；不行就数据备份后换购

## 十、买完下一步做什么（部署顺序预告）

购买成功后，按这个顺序即可（详细命令可另开「部署文档」）：

1. 安装 Docker + Compose  
2. 上传 / `git clone` 本项目代码  
3. 配置服务器上的 `.env`（`APP_ENV=prod`、强密码、LLM Key）  
4. `docker compose up --build -d`  
5. 浏览器访问 `http://公网IP:5173` 与 `http://公网IP:8000/docs`  
6. 验收登录、上传文档、问答

## 十一、常见问题

**Q：轻量和 ECS 买哪个？**  
A：个人/小团队演示优先 **轻量**；要更灵活的网络和规格再选 ECS。

**Q：学生机 2核2G 行不行？**  
A：能练习装 Docker，但本项目带向量时很容易不够内存；正式演示仍建议 **4核8G**。

**Q：必须备案吗？**  
A：只用 IP 访问 → 一般不用。用国内域名 + 国内服务器网站服务 → 通常要备案。

**Q：能否先买一个月试试？**  
A：可以，包月买 1 个月，跑通再开自动续费。

**Q：和「分开买 RDS」比哪个便宜？**  
A：一台轻量全装通常更便宜；本方案就是按这个思路买的。
