## 二、推荐简历条目（可直接粘贴）

### 版本 A｜偏后端 / AI 应用（推荐 4～6 条）

**企业知识库 RAG + Agent 智能问答平台**｜独立开发 / 全栈  
技术栈：`Python` `FastAPI` `Vue3` `TypeScript` `PostgreSQL` `Qdrant` `Redis` `Docker` `LangGraph` `JWT` `SSE`

- 设计并实现企业文档 **RAG 全链路**：PDF/DOCX/TXT/MD 解析 → 中文切块 → Embedding（BGE-M3）→ Qdrant 入库 → 问答检索生成，文档状态可追踪（uploaded→ready/failed）。
- 实现 **向量检索 + PostgreSQL 全文/关键词检索** 的混合召回，经 **RRF 融合** 与可选 **CrossEncoder 精排**，将 Top 片段注入 Prompt；无命中时明确返回「知识库未覆盖」，降低幻觉。
- 基于 **OpenAI 兼容接口** 对接大模型（DeepSeek 等），问答与 AI 文档创作支持 **SSE 流式输出**；前端边收边渲染 Markdown，并展示引用来源卡片。
- 实现 **Agent 模式**：以 ReAct（JSON action）+ **LangGraph** 多步调度，工具白名单注册（天气 / 知识库统计 / 只读 SQL 等），完成 retrieve→execute→finish 循环。
- 完成多租户权限体系：JWT（access/refresh）+ bcrypt、角色（超管/部门管理员/成员）与知识库 **ACL**；统一 `AppError` 错误信封、CORS、请求 ID 与 JSON 日志。
- 使用 **Docker Compose** 编排 PostgreSQL / Redis / Qdrant / 前后端，支持本地一键拉起依赖；提供 Swagger（`/docs`）便于联调。

### 版本 B｜偏全栈（前后端都写一点）

**企业知识库智能问答平台**｜Vue3 + FastAPI  

- 前端：Vue3 + TS + Pinia + Element Plus，实现登录、知识库/文档管理、智能问答（SSE）、历史会话、数据统计图表与用户权限管理页。
- 后端：FastAPI 异步 API，完成认证鉴权、文档流水线、混合检索 RAG、Agent 工具调度与统一异常处理。
- 数据层：PostgreSQL 存业务与切块文本，Qdrant 存向量；Redis 用于令牌黑名单/登录锁定与可选 Celery 任务队列。
- 业务亮点：多租户隔离、答案引用溯源、AI 创作文档入库、会话可见性按角色控制、管理员上传统计看板。

### 版本 C｜极简 3 条（一页纸简历挤位置时）

- 独立完成企业 RAG 问答系统：文档解析切块向量化、混合检索 + 大模型流式生成，答案带原文引用。
- 实现 JWT 多租户权限与知识库 ACL；Agent 模式下基于 LangGraph 调度白名单工具。
- Docker Compose 部署 PostgreSQL / Redis / Qdrant，前后端分离（FastAPI + Vue3）。

## 四、面试口述稿（1 分钟）

我做了一个面向企业内部的知识库问答平台。管理员上传制度、手册类文档后，系统会解析、切块、用 BGE 做向量并写入 Qdrant，同时在 PostgreSQL 里保留文本和全文检索能力。员工提问时，先做向量+关键词混合召回，再 RRF 融合和精排，把最相关片段交给大模型，用 SSE 流式返回答案，并挂上引用来源，避免瞎编。另外做了 Agent 模式，用 LangGraph 让模型在检索和工具调用之间多步决策。权限上是多租户 + JWT + 知识库 ACL。技术栈是 FastAPI + Vue3，依赖用 Docker Compose 拉起。

## 五、可能被追问的点（建议提前答熟）

| 问题 | 建议答法（贴合本项目） |
|------|------------------------|
| 为什么用 Qdrant 不把向量放 PG？ | 向量检索与业务库负载隔离；按知识库建集合，过滤清晰。 |
| 混合检索为什么必要？ | 纯向量对专有名词/编号不稳；关键词补召回，RRF 融合更稳。 |
| 如何减少幻觉？ | 系统提示约束只依据检索结果；低相关/无命中明确「未覆盖」；答案带来源 chunk。 |
| Agent 是不是原生 Function Calling？ | 本项目是 ReAct：模型输出 JSON action，白名单 `run_tool` + LangGraph 调度；思路等价，协议自研。 |
| 流式怎么做的？ | 后端 `StreamingResponse` + `text/event-stream`；前端 `fetch` 读流，事件含 delta/citation/tool。 |
| 向量模型在哪跑？ | 默认本机 sentence-transformers 按需加载；大模型默认云端 OpenAI 兼容 API。 |
